# 🌐 Personal Portfolio

Live Demo: https://awsmx.vercel.app/

## 🚀 Overview

This is my personal portfolio website showcasing my work, skills, and projects as an aspiring Machine Learning Engineer and Full Stack Developer.

The site focuses on clean design, smooth user experience, and practical project presentation.

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Flask
* **Deployment:** Vercel

## ✨ Features

* Responsive and modern UI
* Smooth navigation and clean layout
* Project showcase section
* Skills and contact sections
* Optimized performance for fast loading

AI tools were used to enhance UI/UX decisions, improve layout structure, and refine design elements for a better user experience.
